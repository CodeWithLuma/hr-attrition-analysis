# Data source

Dataset: IBM HR Analytics Employee Attrition & Performance (Kaggle)

- Link: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset
- File: `WA_Fn-UseC_-HR-Employee-Attrition.csv`
- Contents: 1,470 employees, 35 columns, one row per employee.
  No missing values.

## How to get it

1. Open the Kaggle link above (free Kaggle account needed to download).
2. Download `WA_Fn-UseC_-HR-Employee-Attrition.csv`.
3. Put the file in this `data/` folder, next to this note.

The dataset file itself is not included in this repo.

## A note on the data

This dataset is simulated data created by IBM for education and analysis
practice. It is not a real company's workforce, so findings from it are
an analytical exercise, not facts about any real employer.
